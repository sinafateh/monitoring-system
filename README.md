# سامانه مدیریت و مانیتورینگ پنل‌های اعلام حریق

این نسخه‌ی اولیه یک پوسته‌ی RTL برای نصاب‌ها و اولین قابلیت عملیاتی رابط کاربری را فراهم می‌کند:

- ساختار داشبورد با سایدبار، هدر، پروژه‌ی فعال و وضعیت اتصال
- مسیر طراحی‌شده برای پروژه‌ها، مانیتورینگ، پنل‌ها، رویدادها، گزارش‌ها و تنظیمات
- صفحه‌ی «تنظیمات سیستم ← تاریخ و زمان»
- تقویم شمسی با انتخاب روز، جابه‌جایی ماه و دکمه‌ی امروز
- فیلد ساعت جداگانه با فرمت ۲۴ ساعته
- نگه‌داری وضعیت فرم و پیام وضعیت برای اتصال/اعمال روی پنل

اتصال واقعی به پنل، احراز هویت، پروژه‌ها و همگام‌سازی در این مرحله فقط به‌صورت چارچوب و وضعیت نمایشی هستند.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی production:

```bash
npm run build
```
